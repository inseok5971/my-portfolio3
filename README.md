## ✨ 핵심 구현 기능

### 1. 기본 템플릿 & 추천 템플릿 목록 (이미지 1)
- **대표 템플릿**: 이미지 1의 **'캐릭터 카드뉴스'** 기본 탑재
  - 하늘색 체크 배경
  - 서류철 폴더 형태의 화이트 카드 레이아웃
  - "강조 텍스트가 들어갑니다." 블랙 말풍선 배지
  - 메인 타이틀: "캐릭터" (블루), "카드뉴스" (블랙)
  - 귀여운 벡터 캐릭터 3종 (아기새, 젤리 공룡, 구름 마스코트)
  - 하단 구분선 & "미리컴퍼니"
- **추천 템플릿 바**: 좌측 사이드바에 '기쁨가득', '쉽고 귀여운', '심플한', '비즈니스', '와글와글' 등 다양한 테마 템플릿을 한 번의 클릭으로 즉시 교체 적용 가능
- **하단 슬라이드 바**: 1, 2, 3... 멀티 슬라이드 추가 및 전환 관리, 확대/축소/화면맞춤

### 2. 세부 텍스트 서식 툴바 (이미지 2)
선택한 텍스트 항목에 대해 다음 기능들을 실시간으로 조작할 수 있습니다:
- **글꼴(Font)**: 프리텐다드 Bold, Noto Sans KR, Black Han Sans, 나눔고딕 등
- **글자 크기**: `[-]`, `[+]` 스텝퍼 및 숫자 직접 입력
- **글자 색상**: 컬러 피커 연동 (A 아이콘)
- **형광펜 / 배경색**: 텍스트 배경 하이라이트 색상
- **스타일**: 볼드(B), 이탤릭(I), 밑줄(U), 취소선(A²)
- **정렬**: 좌측 / 가운데 / 우측 정렬
- **글자 조정**: 자간(Letter spacing), 행간(Line height) 슬라이더 조절
- **효과**: 그림자(Shadow On/Off, 색상, 번짐) 및 외곽선(Stroke 두께, 색상)
- **투명도**: 0% ~ 100% 미세 조절
- **정렬(캔버스 맞춤)**: 가로 중앙, 세로 중앙, 상/하/좌/우 맞춤

### 3. 캔버스 사이즈 조합 & 직접 입력 (이미지 3)
헤더의 사이즈 버튼(`1080×1080 px ▾`) 클릭 시 팝오버 오픈:
- **프리셋**:
  - `1:1 (1080×1080 px)` - 기본 인스타그램 피드
  - `16:9 (1920×1080 px)` - 와이드 가로형 (유튜브 썸네일 / PPT)
  - `9:16 (1080×1920 px)` - 세로형 (인스타 스토리 / 릴스 / 쇼츠)
- **직접 입력 (이미지 3)**:
  - 가로 및 세로 해상도 숫자 입력 (px 단위)
  - **비율 고정 자물쇠 토글 버튼**: 활성화 시 가로/세로 비율을 유지하면서 자동 계산
  - 청록색 `적용` 버튼 클릭 시 캔버스 해상도 및 뷰포트 비율 즉시 재계산

### 4. 엄격한 이미지 업로드 검증
- **JPG, JPEG, PNG 파일만 업로드 허용** (확장자 및 MIME 타입 모두 엄격 필터링)
- 다른 형식(GIF, WEBP, SVG, PDF 등)을 업로드하려 할 경우 경고 알림 토스트 표시 후 자동 차단
- 업로드된 이미지는 사이드바 업로드 갤러리에 저장되어 언제든 클릭으로 재사용 가능

### 5. 객체 잠금(Lock) 기능
- 텍스트, 이미지, 도형 등 모든 요소에 **잠금(Lock)** 기능 지원
- 잠금 활성화 시:
  - 위치 이동 불가 (Drag 방지)
  - 크기 조절 및 회전 핸들 숨김/고정
  - 레이어 순서 변경 및 삭제 방지
  - 테두리가 잠금 상태(빨간색)로 시각적 피드백 제공
  - 툴바의 자물쇠 버튼을 다시 누르면 언제든 간편하게 해제 가능

### 6. 기울기(Skew) 및 회전(Rotate) 설정
- 툴바의 `크기·위치` 메뉴에서 설정 가능:
  - **회전 각도(Angle)**: 0° ~ 360° 슬라이더 조절
  - **가로 기울기(Skew X)**: -45° ~ +45° 텍스트/이미지 기울기 왜곡
  - **세로 기울기(Skew Y)**: -45° ~ +45° 기울기 조절

### 7. 순차배열 (Z-Index 계층 이동)
- 툴바의 `순서` 메뉴에서 원클릭으로 조작:
  - **맨 앞으로 (Bring to Front)**
  - **앞으로 (Bring Forward)**
  - **뒤로 (Send Backward)**
  - **맨 뒤로 (Send to Back)**

### 8. 편리한 단축키 & 고화질 다운로드
- `Delete` / `Backspace`: 선택 요소 삭제 (잠금 시 삭제 방지)
- `Cmd + Z` / `Ctrl + Z`: 실행 취소 (Undo)
- `Cmd + Shift + Z` / `Ctrl + Y`: 다시 실행 (Redo)
- `Cmd + D` / `Ctrl + D`: 객체 복제 (Duplicate)
- 상단 **다운로드** 버튼 클릭 시 고해상도 PNG 파일로 원본 크기 그대로 즉시 다운로드
